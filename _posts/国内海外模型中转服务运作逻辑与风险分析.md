> | 市场规模 | 中国日均 Token 调用量突破 140 万亿，两年增长超千倍 |

前沿大模型（如 GPT-5、Gemini-2.5）的访问面临三道门槛：**价格高**（GPT-5 API 定价 $1.25/$10 per 1M tokens，对学生和研究者构成巨大压力；ChatGPT 端虽有免费层但配额有限）、**支付难**（无国际信用卡无法付款）、**地区限制**（OpenAI/Anthropic 明确禁止中国大陆、俄罗斯、伊朗等地区访问）[^6]。这三重限制直接催生了"影子 API"(shadow API)——第三方中转服务，声称通过间接访问提供官方模型且无地区限制[^12]。在这一背景下，一条以"反向代理 + 账号池"为核心模式的 **AI 中转站**生态应运而生[^3]。中转站站在用户与官方 API 之间，用自己的密钥转发请求，本质上是"API 代购商"[^1]。

市场规模层面，据国家数据局监测，我国日均 Token 调用量从 2024 年初的约 1000 亿激增至 2025 年底的 100 万亿，2026 年 3 月已突破 140 万亿，两年增长超千倍[^17]。中国已是全球 Token 调用量最大的国家，调用量是排名第二的美国的近两倍[^17]。在这一爆发式增长的庞大市场中，中转服务作为连接用户与模型的灰色中间层，其体量与影响不容忽视。

2026 年 3 月，CISPA 亥姆霍兹信息安全中心发布的学术报告（arXiv:2603.01919）揭示了一个触目惊心的事实：**全行业 45.83% 的中转 API 端点存在模型掉包、虚标参数、降智替换等恶性问题**[^12]。这意味着近半数开发者支付的"旗舰模型"费用，换来的可能是"缩水模型"的服务。2026 年 5 月，上海一名中转站站长因涉嫌非法经营罪被刑事拘留 37 天；6 月 8 日，国家安全部正式发布风险提示[^6]。本报告系统梳理中转服务的运作逻辑、渠道全景、低价成因与潜在风险。

## 一、运作逻辑

### 1.1 核心架构：三层处理与请求路径

AI 中转站本质是一个 API 聚合与分发平台，用户把请求发给中转站，中转站用自己的密钥调官方 API，拿到结果再返回给用户[^1]。请求路径为：

```
你的应用 → 中转站服务器 → 官方 API(OpenAI/Claude/Gemini) → 中转站 → 你的应用
```

一次请求在中转站内部通常经过三层处理[^3]：

- **接入层**：Cloudflare、Nginx、APISIX 等网关，负责挡异常流量、保持长连接、处理跨域和超时。
- **鉴权层**：中转站查验用户的 sk-relay-key 属于谁、余额多少、用户在哪个分组、能否调用该模型。
- **计费预估层**：系统粗略估算输入 Token 数，检查余额，必要时先冻结一部分额度。

关键技术特性：几乎全部支持 OpenAI 兼容格式（已成"行业标准"）、通过 SSE 实现流式输出、智能调度多个上游 API Key 做负载均衡、底层框架绝大多数基于开源项目 One API 或其衍生版 New API 搭建[^1]。CISPA 学术报告的审计印证了这一判断：在识别出的 17 个影子 API 中，**11 个基于 OneAPI/NewAPI 构建**[^12]。OneAPI 将各商业 LLM 提供商的接口统一为标准 OpenAI 兼容格式，支持 API Key 管理、二次分发、请求路由和自动重试，极大降低了搭站门槛，也放大了被转售和滥用的可能性。

### 1.2 渠道分类：8 大技术组别

中转站真正分叉在路由层，决定了钱从哪来、风险从哪来。按**技术来源**，行业可细分为 8 个组别[^2][^4]：

| # | 渠道组别 | 本质 | 保真度 | 稳定性 | 价格（官方为1.0） | 风险 | 适合场景 |
|---|---------|------|--------|--------|----------------|------|---------|
| 1 | 官转 | 原厂授权批量采购转卖 | 最高 | 高 | 0.5~1.0 | 🟢 | 企业核心业务 |
| 2 | Max 套餐 | 代理商打包优惠套餐拆分 | 较高 | 中等 | 0.6~0.8 | 🟢 | 中小团队开发调试 |
| 3 | Vertex | 谷歌云/亚马逊云资源池 | 高 | 较高 | 0.8~1.2 | 🟢 | 多模态/生图类产品 |
| 4 | Kiro | 境外小工作室薅免费额度 | 不确定 | 偏低 | 0.1~0.3 | 🟡 | 仅小额试用 |
| 5 | 逆向 | 抓包破解官方链路 | 极低 | 极差 | 0.05~0.3 | 🔴 | 不推荐任何场景 |
| 6 | 定制企业包 | 大集团定向采购 | 高 | 高 | 波动大 | 🟢 | 大型企业内部 |
| 7 | 个人共享额度 | 个人账号多人拼车 | 不确定 | 低 | 0.1~0.5 | 🟡 | 散户小额试用 |
| 8 | 开源聚合 | 技术爱好者自建 | 看上游 | 看运维 | 极低~免费 | 🟡 | 技术爱好者自用 |

> 风险标识：🟢 低风险 · 🟡 中风险 · 🔴 高风险（涉刑）

**逐个详解**：

**1. 官转渠道**：原厂官方授权的大客户额度拆分。中转站以大客户身份向 OpenAI/Anthropic 批量采购 API 额度，获得企业级折扣后拆分转卖。保真度 100%，计费规则与响应参数与原厂完全一致，是所有渠道中质量最高的。缺点是采购成本偏高，严格原厂授权批采通常 7-10 折，但部分平台将"池化订阅拆卖"也包装成"官方渠道"出售，价格可低至 5 折，因此市面标价区间为 5-10 折[^2]。

**2. Max 套餐**：代理商大额采购厂商批量打包优惠套餐后拆分分销。与官转的区别：官转是"按需采购额度再转卖",Max 套餐是"厂商推出的固定打包优惠套餐"（类似运营商流量包）。价格约为官方原价的 6-8 折，低于严格原厂批采价 20%-40%，但部分套餐存在额度限量、限时关停风险[^2]。

**3. Vertex 渠道**：依托谷歌云（GCP Vertex AI）、亚马逊云（AWS Bedrock）等企业级云资源池搭建。底层云服务器资源充足，多模态图文生成接口稳定性突出。但接口协议经过云端二次封装，部分小众模型能力存在小幅阉割。价格区间 0.8-1.2，部分反而高于官方[^2]。

**4. Kiro 渠道**：2026 年初新出现的渠道类型。AWS 于 2025 年 7 月推出 AI IDE Kiro，底层调用 Claude 模型，新用户注册送 550 积分（含 500 新人奖励+50 月度额度，2026 年初数据）。海外小众代理服务商批量注册 AWS Builder ID 账号薅免费积分，用 kiro-gateway、AIClient-2-API 等工具将 Kiro 私有协议转为标准 API，定向分发给国内中转站。价格优势突出（0.1-0.3），但服务商主体多为境外小型工作室，无固定履约保障；且 2026 年 5 月后 AWS 推出 Kiro Pro（$20/月）付费套餐，免费积分政策面临调整风险[^1][^20]。

**5. 逆向渠道**：行业风险最高的类型。通过抓包破解官方网页版或客户端通信协议，把浏览器里才能用的聊天功能"变成" API，无原厂授权。随时面临接口封禁、模型参数篡改，是 CISPA 报告中掉包率最高的渠道类型[^12]。详见 1.3 节。

**6. 定制企业包**：大型集团客户与模型厂商或一级代理商签订定制协议，按企业需求采购专属额度池，通常伴随私有化部署、专属 SLA、审计合规等企业级条款。不面向散户，定价波动大且通常有保密协议[^2]。

**7. 个人共享额度**：个人账号多人"拼车"。有人购买 ChatGPT Plus（$20/月）或 Claude Pro（$20/月）订阅，把账号共享给几十人，通过中转站分摊费用。保真度不确定，稳定性低（账号易被封）[^2]。

**8. 开源聚合**：技术爱好者基于 One API / New API / CPA 等开源项目自建，接入自己持有的各种上游渠道统一管理。价格极低甚至免费，但稳定性完全取决于部署者的运维能力和上游渠道质量[^2]。

### 1.3 逆向渠道深度解析

> **为什么单独深挖逆向渠道**：8 大组别中，官转/Max 套餐/Vertex/定制企业包本质是合法采购转售，运作逻辑已在 1.2 节阐明；个人共享额度技术实现简单（账号多人拼车），无独立分析必要。Kiro 渠道虽在 1.2 节中单独列出，但其核心技术手段（OAuth 授权逆向、私有协议转 OpenAI API）本质属于逆向工程范畴，将在本节"AWS-Q/Kiro 渠道"分支中一并分析。逆向渠道整体兼具技术复杂度高、行业渗透率大、法律风险最高三重特征，且是 CISPA 报告中掉包率最高的渠道类型，因此单独成节深入剖析。

逆向渠道是 8 大组别中风险最高、技术最复杂的类型，已分化出四大技术分支并形成完整产业链。

#### 1.3.1 四大技术分支

| 技术分支 | 原理 | 代表项目 | 成本 | 稳定性 |
|---------|------|---------|------|--------|
| **2API（订阅转API）** | 逆向 ChatGPT Plus/Claude Pro 网页版协议，将订阅额度转成 API | Sub2API | 极低（月费÷几十人） | ★★ |
| **AWS-Q/Kiro 渠道** | 逆向 AWS Q Developer 或 Kiro IDE 的 OAuth 认证，白嫖免费 Claude | kiro-gateway、AIClient-2-API | 零（薅免费积分） | ★ |
| **浏览器自动化（Web2API）** | 启动无头浏览器，模拟真人操作网页版，读取 Cookie 转发 | openclaw-zero-token（"小龙虾"） | 零（网页版免费） | ★★★ |
| **协议指纹逆向** | 抓包破解官方请求格式，绕过 TLS 指纹/反爬检测 | free-claude-code 等自建项目 | 中（需技术能力） | ★ |

**2API（订阅转API）**：把月费订阅的网页通信逆向成 API 格式。核心流程：注册大量订阅账号 → 逆向分析网页请求格式 → 搭建中间服务器封装请求 → 对外提供 OpenAI 兼容 API[^1]。一个 $20 订阅被几十人"拼车"，人均成本降到几毛钱。

**AWS-Q/Kiro 渠道——"薅大厂羊毛"**：2026 年最火的逆向分支。批量注册 AWS Builder ID 账号（无需信用卡），每个账号获得 550 积分；用开源项目部署协议转换网关，通过 OAuth 绑定多个 Kiro 账号形成账号池，负载均衡分发请求；将 Kiro 私有协议转换为标准 OpenAI API 格式对外服务。一个账号的 550 积分可调用 Claude Opus 4.5 约 250 次，批量注册 100 个账号即可获得 2.5 万次调用，成本为零[^1]。

**浏览器自动化（Web2API）**：2026 年 2 月爆火的开源项目 openclaw-zero-token（俗称"小龙虾",GitHub Star 3 周破 2300、5 月超 5000）代表了另一种思路。不破解协议，而是启动无头浏览器模拟真人操作：读取已登录网站 Cookie，在后台自动打开 AI 网页输入问题、等待回答、提取结果返回。支持 12 个平台 28+ 模型，部署门槛极低（npm install + npm run start）[^1]。

**协议指纹逆向**：更硬核的技术路线。通过浏览器开发者工具抓包分析官方请求的端点、认证头、请求体结构，然后用后端模拟这些请求。难点在于现代反爬系统会检测 TLS 指纹（ClientHello 报文扩展字段顺序）和浏览器指纹（Canvas、WebGL、User-Agent），需要用 curl_cffi 等工具伪造 TLS 指纹才能绕过反爬系统[^1]。

> **⚠️ 2026 年官方封堵潮**
>
> 逆向渠道正面临前所未有的生存压力。
>
> **Anthropic 收紧**：2026 年 4 月 4 日更新服务条款，正式禁止 OpenClaw 等第三方工具使用订阅额度，用户必须切换至按量付费 API;Anthropic 原定 6 月 15 日起实施"双池并行"计费（交互式使用继续享受订阅优惠，程序化调用独立核算，按 API 零售价消耗月度 Credit），但在生效当天因集体诉讼压力和社区强烈反弹而宣布取消，所有程序化使用继续从正常订阅额度中扣除。Anthropic 表示正在重新制定计划，承诺未来变更前会提前通知[^19]。该政策虽已取消，但仍向市场释放了明确信号——官方对第三方工具调用订阅额度的容忍度正在降低，2API（订阅转 API）和浏览器自动化（OpenClaw/"小龙虾"）两大逆向分支面临长期不确定性。
>
> **OpenAI 收紧**：账号风控加强，批量注册账号和异常调用模式的检测精度大幅提升。
>
> **Kiro 收紧**：免费积分政策从早期的 550 积分（新人 500+月度 50）逐步调整，2026 年 5 月已推出 Kiro Pro（$20/月）付费套餐，免费额度面临缩水风险[^20]。
>
> 逆向渠道已从"暴利时代"进入"猫鼠游戏"的高风险阶段。

#### 1.3.2 完整产业链结构

逆向渠道已形成**四层产业链**[^7]：

```
第一层:技术工具提供者(开源项目作者)
  ↓ 提供 One API / New API / AIClient-2-API / openclaw-zero-token / CPA 等工具
第二层:上游账号供应商(批量注册/薅羊毛)
  ↓ 提供账号池或逆向 API 接口
第三层:中转站站长(部署+运营+定价)
  ↓ 批量采购上游,部署中转平台,定价 0.05-0.3 倍率转售
第四层:终端用户(开发者/中小企业)
```

**第一层（工具层）**[^7]：开源项目作者提供基础设施。One API / New API 提供中转站框架，AIClient-2-API、openclaw-zero-token 提供逆向协议转换工具，CPA 提供账号批量注册方案。工具层降低了全行业技术门槛。

**第二层（账号供应）**[^7]：上游供应商批量注册 AWS Builder ID、OpenAI、Anthropic 账号，通过虚拟信用卡、海外手机号绕过注册限制，形成账号池后以接口形式分发给中转站站长。

**第三层（中转站运营）**：站长部署开源中转程序，做自助充值后台、用量统计、会员套餐。行业**盈利结构**[^7]：

| 规模 | 月流水 | 纯利润 | 毛利率 |
|------|--------|--------|--------|
| 小玩家（单人轻资产） | 2-5 万 | 5千-2万 | — |
| 中型站点（有企业客户） | 十几万 | — | 25%-40% |
| 头部站点 | 几十万 | 非常可观 | — |

启动成本极低：一台云服务器 + 开源中转面板，2000-5000 元即可开张[^8]。**引流获客**[^7]：主要靠社群口碑、技术博客、价格对比表传播，用户群体以开发者为主。

### 1.4 附加维度：是否自持上游

除技术来源外，中转站还可按**是否自持稳定上游**[^7]分为两类：

| 模式 | 特征 | 风险 |
|------|------|------|
| 自持上游 | 自己持有官方 Key 或账号池，直接对接模型厂商 | 责任边界清晰，故障可追溯 |
| 二道贩子（小中转接大中转） | 自己不持有稳定上游，再接别人接口，再包装赚差价 | 故障不可解释，责任边界消失 |

这一维度与渠道分类正交：官转站可以自持上游，也可以再接其他官转站；逆向站可以自建账号池，也可以接别人的逆向接口。**多层套嵌**[^7]在逆向渠道中尤为常见，最终用户往往无法追溯请求经过了几层中转。

### 1.5 各渠道代表性厂商

> **说明**：以下**厂商信息综合自**[^8][^9]。该领域大量评测文章带厂商推广性质，下文仅选取有独立验证依据或官方背书的代表性厂商，不构成推荐。

#### 官方真实 Key 渠道（官转/Max 套餐）

- **OpenRouter**：全球最大的模型聚合路由平台，接入超 300 个模型。对海外模型多数走官方授权通道。定价几乎与官方一致（模型单价持平，充值环节收取约 5% 平台服务费），部分模型收取少量溢价。SLA 约 99.5%[^8][^9]。适合个人开发者与原型验证。
- **硅基流动（SiliconFlow）**：国内知名模型推理平台，适配 160 余款模型，对 DeepSeek、Qwen、GLM 等国产开源模型做深度推理优化。新用户注册赠送 2000 万 Token[^8]。适合以国产模型为主的团队。

#### 云厂商渠道（Vertex）

- **阿里云百炼（Model Studio）**：阿里云官方模型服务平台，上架约 150 个模型。原生集成阿里云 RAM 子账号、操作审计、企业发票，官方 SLA 承诺 99.9%[^10]。2026 年起支持通过 OpenAI / Anthropic 兼容协议接入 Claude Code 等编程工具[^10]。
- **AWS Bedrock / Azure OpenAI**：国际云厂商官方授权渠道。AWS Bedrock 于 2026 年 4 月底上线 GPT-5.5 与 Codex 能力[^11]。Azure OpenAI 长期作为 OpenAI 在国内企业级市场的合规通道。适合已在用 AWS/Azure 的企业客户。

#### 逆向渠道

**被查处的案例站点**：2026 年 5 月上海被刑拘的站长"瓜皮"运营的站点是公开披露的典型案例，通过批量注册账号池、逆向协议破解，以远低于官方价格转售，最终被以涉嫌非法经营罪刑事拘留 37 天[^5][^6]。

- **个人运营的 New API 站点**：绝大多数逆向中转站为个人或小团队运营，基于开源 New API 框架一行命令部署，启动成本仅 2000-5000 元[^8]。有报道称一位工厂车间工人照着教程搭建，每天有上千元到上万元充值流水[^7]。

> **提示**：逆向渠道因法律风险高、生命周期短，不存在可持续的"头部厂商"。任何以极低价（官方 1-3 折）宣传的站点，均应视为潜在逆向渠道。

## 二、低价成因：各渠道钱从哪来

### 2.1 三笔钱的本质

中转站赚钱靠的不是模型能力，而是三笔钱[^3]：

- **访问门槛的钱**：用户用人民币充值，后台用虚拟美元计价，甚至出现"1 元人民币 = 1 美刀额度"——所谓"刀"往往不是银行汇率意义上的美元，而是站内额度单位。
- **额度管理的钱**：轻度用户充了 100 元只用了 10 元就停了；重度用户把 Claude Code 接到项目里跑一晚上，站长再靠限速、排队、换上游去扛。
- **信息不透明的钱**：用户买的是"我能用上 Claude"这个结果，但很少能验证背后到底是哪条通道。

### 2.2 各渠道低价来源详解

| 渠道 | 价格（官方为1.0） | 低价来源 |
|------|----------------|---------|
| 官转 | 0.5~1.0 | 批量采购折扣 + 站内汇率（严格原厂批采7-10折，含池化混卖可低至5折） |
| Max 套餐 | 0.6~0.8 | 厂商打包优惠套餐拆分 |
| Vertex（云厂商） | 0.8~1.2 | 厂商合作定价 + 企业账单补贴（部分反而高于官方） |
| Kiro | 0.1~0.3 | 薅 AWS 免费积分（零成本） |
| 逆向 | 0.05~0.3 | 订阅额度共享 + 薅羊毛 + 模型替换 |
| 个人共享额度 | 0.1~0.5 | 订阅账号多人拼车 |

**官转的低价** = 批量采购折扣（5-10 折）+ 站内汇率差。严格原厂授权批采受成本硬约束通常 7-10 折，但市场上部分标称"官转"的平台实际混入池化订阅拆卖资源，价格可低至 5 折。低于 5 折几乎不可能是纯官转[^1]。

**逆向的低价** = 零成本获取调用能力（薅免费额度/共享订阅）+ 模型替换（用低成本模型冒充高端，成本差 10-30 倍）+ 算力消耗压缩（缩短上下文、缓存失效）[^1]。

### 2.3 模型替换与"偷梁换柱"

CISPA 学术报告（arXiv:2603.01919）提供了模型替换的系统性证据[^12]。报告识别出**三种经济欺骗机制**：

| 机制 | 描述 | 示例 |
|------|------|------|
| **信息溢价模式** | 收取高端模型费用，但用更便宜的类似型号替代 | API A 宣传 Gemini-2.0-flash 但实际交付 Gemini-2.5-flash，收取的价格比广告模型官方定价贵 7.1-7.25 倍（实际交付模型比广告模型更便宜，用户损失更大） |
| **折扣替换模式** | 按官方原价收费，但用低成本开源后端替代 | API A 宣传 GPT-5 按原价收费，但指纹显示为 GLM-4-9B |
| **转售加价模式** | 施加小幅加价，同时悄悄替换底层模型 | API H 对 GPT-5 收取 1.09× 官方费率，但交付降级后端 |

关键发现：**CISPA 报告揭示了三种经济欺骗机制**[^12]。模型替换的具体表现：

**LLMmap 指纹检测**[^12]：

- **高端专有模型被替换为开源小模型**：GPT-4o-mini 在影子 API H 中行为偏向 Qwen2.5-7B;GPT-5 在影子 API A 和 E 中指纹类似 GLM-4-9B 或 DeepSeek-V3。
- **推理模型被非推理模型替代**：请求 DeepSeek-Reasoner（思考模式），影子 API A 和 H 实际交付 DeepSeek-Chat（非思考模式）；请求 Gemini-2.0-flash，实际被识别为 Gemini-2.5-flash。
- **身份匹配但行为退化**：Gemini-2.5-flash 在所有受测影子 API 中指纹匹配，但医学（MedQA）准确率从官方 83.82% 骤降至约 37%，说明仅靠身份检查无法确保行为一致性。

### 2.4 其他隐性降价手段

- **上下文窗口缩水**：宣传支持 200K tokens，实际偷偷缩短到 32K 节省成本[^1]。
- **缓存机制失效**：Claude、GPT 等支持 Prompt Cache 的模型，中转站往往无法继承官方缓存机制，看似便宜实际 Token 消耗比官方更多[^4]。
- **System Prompt 劫持**：部分中转站在提示词前偷偷注入广告或限制，影响输出质量[^1]。
- **账单注水**：实际消耗 1000 token，账单显示 1500。2026 年 ACM 互联网测量大会论文指出，部分网关实际收费比预期高 62.8%[^14]。

### 2.5 启动成本极低

开源项目（如 New API）已把代理转发、计费系统、用户管理全部打包好，一行命令就能部署，2000-5000 元即可开张[^8]。

## 三、潜在风险

### 3.1 数据安全风险

所有请求都会经过中转服务器，企业机密文档、客户数据、代码仓库内容都有可能被平台获取[^3]。国家安全部风险提示明确指出：部分中转站私自截留用户数据倒卖给模型厂商用于系统训练；有的甚至暗藏后门程序，向用户设备植入恶意代码，借机窃取账号密钥与云端凭证[^6]。

### 3.2 模型质量与稳定性风险

CISPA 报告提供了量化证据[^12]：

| 风险类型 | 量化数据 |
|---------|---------|
| 端点模型身份造假 | 45.83% 未能通过指纹验证 |
| 性能偏差 | 最高达 47.21%(Gemini-2.5-flash MedQA: 83.82% → 37%) |
| 安全行为不可预测 | 有害性得分被低估约 0.23 或放大至近两倍 |
| 推理延迟波动 | 影子 API 波动性经常超过官方的 2.0 倍 |
| 合规性缺失 | 88.2% 由个人运营，无可验证身份 |

具体表现包括：模型替换（挂羊头卖狗肉）、账号封禁（共享账号池被检测到异常行为后 API 失效、余额清零）、接口不稳（高峰期频繁掉线）、缓存失效（Token 消耗异常增加）[^3]。

**用户损失量化**：CISPA 报告以 GPQA 上的 GPT-5 查询为例（n=1,273 次，官方定价 $1.25/$10.00 per 1M tokens），计算了模型替换带来的直接经济损失[^12]。影子 API A 按官方费率收费（价格比 1.00×），但只交付了 **38%** 的输出量。用户支付 $14.84，实际收到的输出按 token 量计算仅值 $5.70~$7.77，提供商每 1,273 次查询捕获 $7.07~$9.14 利润。归一化到任务准确率，影子 API **每美元实际交付价值产生的错误比官方端点多 2~4 倍**——即用户花同样的钱，得到的错误答案数量是官方的 2-4 倍。

### 3.3 资金安全风险

很多中转站属于个人运营项目，无公司主体、无备案信息、无正规合同、无资金监管[^3]。用户充值后，平台可能突然关站、失联跑路。2026 年上海被刑拘的站长公开表示，中转站没赚到钱，也无力赔偿用户充值款[^6]。

### 3.4 内容安全风险

中转平台理论上可对模型返回结果进行二次修改：代码中植入恶意逻辑、返回广告内容、篡改技术答案、注入钓鱼链接[^7]。2026 年 3 月 24 日，LiteLLM（Python 生态最主流的开源 AI 网关，GitHub Star 超 4 万、月下载量近 9700 万）其 1.82.7 和 1.82.8 两个版本遭供应链投毒攻击，恶意代码自动窃取 SSH 密钥、云凭证、API Key 等敏感数据并加密回传，短期内可能有数万至数十万实例暴露，所有依赖 litellm>=1.64.0 的项目均受波及[^18]。

### 3.5 学术研究风险

CISPA 报告揭示了一个更深层的影响：17 个影子 API 已被 187 篇学术论文使用，最热门的一个被引用 5,966 次、GitHub Star 58,639[^12]。中国作者占比高达 82.12%。这意味着部分学术结论可能建立在错误的数据基础上，严重损害科学研究的可重复性和有效性[^12]。

**大学实验室也在运营影子 API**：报告披露，影子 API B 由一所**中国知名大学的实验室**部署，基于 NewAPI 搭建，其内部大语言模型市场中列出的部分模型被平台自己标注为"来源不明"[^12]。这意味着连学术机构自己都在运营不透明的中转服务，学术诚信风险比外界想象得更严重。

**学术研究总成本估算**[^12]：保守估计 187 篇论文中 30%（约 56 篇）需要因身份不一致而重新执行（低于实测 45.83% 的指纹失败率），每篇 API 重跑费用 $50~$500，研究者时间约 $2,000（40 小时 × $50/小时），总直接成本达 **$115,000~$140,000**。此估算尚未计入 5,966 篇引用这些论文的下游可重复性成本——沉默的模型替换可能在依赖链中无声地腐蚀实验结果，且不产生任何可见的错误信号。

### 3.6 法律风险：首起刑拘案件

2026 年 5 月，网名为"瓜皮"的上海 AI 中转站站长被公安机关刑事拘留 37 天，取保候审后公开发文承认，曾用非法技术手段获取廉价大模型，已退赔退赃并缴纳罚金。案件案由存在不同说法：公开声明中提及"非法获取 API 模型"，有报道称以"提供侵入计算机信息系统程序"罪名立案[^6]。

京都律师事务所徐伟律师分析认为，案件核心争议聚焦于刑法第二百二十五条非法经营罪兜底条款的适用边界[^5]。通过逆向工程绕过平台技术保护措施，可能面临 3 到 7 年刑期[^6]。

**合法与非法的界限**[^5]：

| 行为 | 法律定性 |
|------|---------|
| 通过正常注册、付费获取官方 API 并做转发代理 | 民事范畴 |
| 采用"逆向工程"对境外大模型网页版接口进行协议破解，包装成 API 转售 | 涉嫌违法 |

**其他渠道的法律定性**：Kiro 渠道和个人共享额度渠道虽不涉及协议逆向破解，但批量注册账号薅免费积分、共享订阅账号等行为违反了 AWS/OpenAI/Anthropic 的服务条款，属于合同违约范畴。此类渠道主要面临账号封禁、余额清零等民事风险，目前尚未见刑事追诉案例，但随着监管趋严，未来不排除被纳入非法经营罪兜底条款的适用范围。

### 3.7 监管动态：合规风暴来袭

2026 年 6 月 8 日，国家安全部正式发布风险提示[^6]。此外，国家网信办等七部门 2023 年 7 月联合发布、同年 8 月 15 日起施行的《生成式人工智能服务管理暂行办法》明确要求，提供生成式人工智能服务需具备相应资质并完成算法备案；该办法自 2026 年起执法力度显著加强，未经备案的中转服务均涉嫌违规。行业门槛正在迅速提高：上游渠道商开始要求 ICP 备案，核心条件包括依法设立的公司、注册资金达标（省内 100 万元起）等 7 项硬性指标[^6]。

### 4.1 渠道全景对比

| 维度 | 官转 | Max套餐 | Vertex | Kiro | 逆向 | 定制企业包 | 个人共享 | 开源聚合 |

| 价格（官方为1.0） | 0.5-1.0 | 0.6-0.8 | 0.8-1.2 | 0.1-0.3 | 0.05-0.3 | 波动大 | 0.1-0.5 | 极低-免费 |
| 稳定性 | ★★★★★ | ★★★ | ★★★★★ | ★★ | ★ | ★★★★★ | ★★ | 看运维 |
| 模型保真度 | 最高 | 较高 | 高（小幅阉割） | 不确定 | 极低 | 高 | 不确定 | 看上游 |
| 法律风险 | 🟢 无 | 🟢 无 | 🟢 无 | 🟡 较高 | 🔴 高（涉刑） | 🟢 无 | 🟡 中 | 🟡 看上游 |

### 4.2 选型六维评估框架[^1]

- **稳定性**：查看 SLA 承诺，优质平台达 99.9% 以上。
- **渠道透明度**：明确说明属于 8 大组别中的哪一类，避免"偷梁换柱"。
- **价格合理性**：官转倍率 0.5-1.0 是正常范围（严格原厂批采7-10折，含池化混卖可低至5折），低于 5 折必有猫腻。
- **网络质量**：有香港/新加坡节点或国内 CDN 加速。
- **安全保障**：明确数据隐私政策，承诺不记录对话内容。
- **技术支持**：有活跃的社群或客服。

### 4.3 警惕信号[^1][^7]

- 🔴 价格低于官方 5 折，几乎必为逆向或模型替换。
- 🔴 无公司主体、无备案信息、无正规合同、无资金监管。
- 🟡 拒绝提供费用明细（输入/输出/缓存 Token 分项）。
- 🟡 上下文窗口与官方不符（可用超长文本测试）。

### 4.4 审计验证协议（基于 CISPA 报告建议）[^12]

CISPA 报告建议的四阶段验证协议可作为企业选型评估框架。

**为什么需要四阶段而非单一检测**：CISPA 报告的 OLS 回归分析揭示了一个结构性异常——**指纹匹配不等于行为一致**[^12]。以 Gemini-2.5-flash 为例，在所有受测影子 API 中指纹验证均通过（余弦距离接近官方基线），但医学和法律领域准确率仍急剧下降。这意味着仅靠身份检查（单一指纹检测）会漏掉"身份正确但后端行为被篡改"的情况，必须叠加分布检验和稳定性测试才能全面覆盖。论文中 LLMmap 与 MET 两种方法在 74.1% 的案例中达成一致（Cohen's κ=0.512），印证了多方法交叉验证的必要性。

| 阶段 | 方法 | 判定标准 |
|------|------|---------|
| 1. 指纹检测 | 用 LLMmap 等工具验证模型身份 | 余弦距离超过官方基线 1.2× 则标记 |
| 2. 分布检验 | 用 MET 统计检验 | 输出分布与官方不一致则标记 |
| 3. 稳定性测试 | 至少 3 次独立运行 | 准确率标准差超过 5 个百分点则标记 |
| 4. 合规验证 | 验证 ICP 注册和法律实体披露 | 无注册身份的个人运营端点携带更高风险 |

社区开发者已开源了审计工具 api-relay-audit，一条命令即可对中转站进行 13 项检测（模型身份、prompt 注入、上下文截断、工具调用改写等）[^15]。

## 总结

国内海外模型中转服务按技术来源可分为 8 大组别：官转、Max 套餐、Vertex、Kiro、逆向、定制企业包、个人共享额度、开源聚合[^2]。其中逆向渠道已分化出四大技术分支（2API、AWS-Q/Kiro、浏览器自动化、协议指纹逆向），并形成"工具层→账号供应→中转运营→终端用户"的四层产业链[^7]。

低价来源因渠道而异：官转靠批量采购折扣（合理，5-10 折，严格原厂批采7-10折，含池化混卖可低至5折）；逆向靠零成本获取调用能力 + 模型替换 + 算力压缩（不合理，1-3 折）[^1]。CISPA 学术报告（arXiv:2603.01919）以量化证据揭示了行业现状：45.83% 的端点模型身份造假，性能差距最高达 47.21%，且定价对准确率下降没有预测力[^12]。

潜在风险覆盖数据安全（隐私泄露、后门植入）、模型质量（替换、阉割、不稳）、资金安全（跑路、清零）、学术研究（187 篇论文受影响）、供应链安全（LiteLLM 投毒事件波及数万开发环境）和法律合规（非法经营罪、3-7 年刑期）[^6][^18]。2026 年 5 月上海首起刑拘案件、6 月国家安全部风险提示，叠加 Anthropic 4 月封杀 OpenClaw 等第三方工具、6 月宣布但随即撤回 Claude Code 独立计费计划，标志着这条灰色产业链正面临"法律打击+官方封堵"双重合规风暴[^6][^19]。

对用户而言，官转渠道（官方 5-10 折，严格原厂批采7-10折）在合规与成本间取得平衡；逆向渠道虽极低价但风险极高，不适合任何生产环境。选型时应遵循 CISPA 报告建议的四阶段验证协议（指纹检测 → 分布检验 → 稳定性测试 → 合规验证），并利用开源审计工具进行实测[^12][^15]。
